# 🛡️ Security Policy

We take the security of our software repositories and profile assets seriously.

---

## 🔒 Supported Versions

Only the latest `main` branch version of repositories maintained under [@bilalchannar](https://github.com/bilalchannar) receives security updates.

| Version | Supported |
| :--- | :---: |
| `main` / Latest Tag | ✅ Yes |
| Pre-release / Legacy | ❌ No |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or potential security risk:

1. **Do NOT open a public GitHub issue.**
2. Send an email directly to **bilalchannar01@gmail.com** with the subject line: `[SECURITY VULNERABILITY] <Project Name>`.
3. Include detailed steps to reproduce the vulnerability, proof-of-concept code, or HTTP request payloads.
4. We will respond within **48 hours** to acknowledge your report and coordinate a patch release.

Thank you for helping keep our software secure!
