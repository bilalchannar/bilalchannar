# 🤝 Contributing Guidelines

Thank you for considering contributing to open-source projects maintained by **Bilal Tariq** ([@bilalchannar](https://github.com/bilalchannar))!

---

## 📜 Code of Conduct

All contributors are expected to adhere to our [Code of Conduct](CODE_OF_CONDUCT.md). Please read it to understand expected behaviors and reporting procedures.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/bilalchannar/bilalchannar/issues) before opening a new report.
- Use the **Bug Report** issue template.
- Provide step-by-step reproduction steps, environment info, and error logs.

### 2. Suggesting Enhancements
- Open a **Feature Request** issue to discuss proposed features before writing extensive code.
- Explain the motivation, proposed solution, and alternative approaches.

### 3. Submitting Pull Requests
1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/my-awesome-feature
   ```
2. Commit your changes using **Conventional Commits**:
   ```bash
   git commit -m "feat: add user authentication rate limiter"
   ```
3. Push to your branch and submit a Pull Request targeting `main`.
4. Ensure all CI checks and linting pass cleanly.

---

## 🎨 Conventional Commit Standards

| Type | Prefix | Description | Example |
| :--- | :--- | :--- | :--- |
| **Feature** | `feat:` | Adds a new feature | `feat: implement PDF text extraction` |
| **Fix** | `fix:` | Fixes a bug | `fix: resolve rate limiter memory leak` |
| **Docs** | `docs:` | Documentation update | `docs: update setup steps in README` |
| **Refactor**| `refactor:` | Code restructuring | `refactor: optimize Cosine Similarity scoring` |
| **Style** | `style:` | Code formatting | `style: run dartfmt on widget trees` |
| **Test** | `test:` | Adding unit tests | `test: add unit test for JWT verification` |
